# Notify Mod Wiki

Notify Mod muestra mensajes de chat, tarjetas del HUD y presentaciones con líneas de tiempo en Minecraft Fabric.
El servidor decide qué enviar y el cliente dibuja los textos, modelos y animaciones.

Notify Mod displays chat messages, HUD cards and timeline presentations in Minecraft Fabric. The server controls
delivery; the client renders text, models and animations.

|---|---|

Esta wiki describe el código disponible. El [plan de diseño](https://github.com/AloneX15/Notify-Mod/blob/main/NotifyMod_Plan.md)
incluye funciones futuras que aún no se pueden usar. Los recursos de `src/gametest` son ejemplos de pruebas y no se
distribuyen en el jar normal. The design plan includes future features; test resources are not shipped in the normal jar.
